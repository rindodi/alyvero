# Alyvero agent guide

## Purpose

Alyvero is a browser-first online utility platform for common PDF and image file tasks.

## Product rules

- Keep core file processing simple and usable without an account.
- Preserve the existing tool URLs and canonical domain: https://www.alyvero.co.ke
- Do not remove working tools or change supported formats without checking the tool implementation.
- Keep privacy, terms and contact pages crawlable.
- Prefer useful, task-specific copy over generic SEO filler.

## Tool families

PDF tools cover PDF to Word, Compress PDF, Merge PDF, Split PDF and PDF to JPG.

Image tools cover Compress Image, HEIC to JPG, Image to PDF, Resize Image and JPG to PNG.

## SEO and accessibility

- Every indexable page should have a unique title, description and self-referencing canonical.
- Keep sitemap and robots resources valid.
- Keep structured data consistent with the visible page and avoid duplicate entities.
- Use descriptive link text and accessible names.
- Do not block legitimate search or AI crawlers.

## Validation

Before merging substantial changes, run the repository's typecheck, production build and end-to-end checks where available.
